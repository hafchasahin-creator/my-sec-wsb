How to install (phone / tablet)

  1. Tap the Download button above.
  2. Open the downloaded BaseHouse.mcaddon file — Minecraft will open and import the pack automatically.
  3. Create or edit a world → Behavior Packs → activate Beautiful Base House.
  4. In the same world settings, turn on Activate Cheats (needed for the build command).
  5. Enter the world, open chat and type:
/function base/house
Your house appears instantly right next to you — the front door is on the sunny side two blocks ahead (+Z). 🏡
⚠ Stand in a flat, open spot: the command clears and builds an area of about 13×13 blocks extending east/south (+X/+Z) of where you stand. You can run the command as many times as you like, anywhere, to build more houses.

What you get

  • 11×9 cozy cottage — oak walls, log corner pillars and a stepped spruce gable roof with overhang.
  • Eight big windows so it's bright inside, plus a real working front door.
  • Workshop corner: crafting table, furnace, smoker and a double chest.
  • Reading corner with bookshelves and torches.
  • Hanging lantern under the ridge beam and lantern posts framing the porch.
  • Stone porch & path leading up to the door — fully lit, so no mobs spawn inside.
Made for Bedrock 1.21.0.26 (works on 1.21.0 and newer, phones included).
