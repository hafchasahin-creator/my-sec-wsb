# Source: Bedrock-OSS/bedrock-wiki, docs/particles/vanilla-particles.md
# (community-curated, not a Mojang asset - unlike vanilla_sound_ids.txt, which
# comes straight out of Mojang/bedrock-samples).
#
# Only the WORKING list is safe for dimension.spawnParticle: everything under
# OTHER either needs Molang context from a host entity, is a bubble/underwater
# effect, or is one of the legacy short names. Those spawn nothing useful when
# called standalone, which is indistinguishable in game from a typo.
#
# tools/build.py fails any particle id in a behaviour script that is not in the
# WORKING list. If you are confident about one that is misclassified here, add
# it to Addon.EXTRA_WORKING_PARTICLES in build.py with a note.
