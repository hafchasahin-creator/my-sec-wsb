Model announcement

Claude Fable 5 aur Claude Mythos 5 ka introduction

Claude Fable 5 aur Claude Mythos 5 ki capabilities, API mein kya-kya badla hai, aur availability — poori detail ke saath.

Note

Yeh Anthropic ke official documentation page ka unofficial Hinglish roopantar hai, sirf padhne-samajhne ki aasaani ke liye. Kisi bhi confusion ki soorat mein official English page hi final maana jayega.

Tip

Claude Fable 5 aur Claude Mythos 5 ka access wapas bahal kar diya gaya hai. Zyada jaankari ke liye hamara statement dekhein.

Claude Fable 5 Anthropic ka sabse capable widely released model hai, jo sabse mushkil reasoning aur lambe chalne wale (long-horizon) agentic kaam ke liye banaya gaya hai. Claude Mythos 5 ki capabilities bilkul wahi hain, lekin yeh sirf limited release mein Project Glasswing ke through available hai.

Integrations ke liye sabse bada badlaav yeh hai: Claude Fable 5 mein safety classifiers hain jo kuch requests ko decline kar sakte hain. Claude Mythos 5 mein yeh classifiers nahi hain. Agar aapka integration Claude Fable 5 ko call karta hai, toh teen cheezon ki planning kar lein — refusals ke liye naya response handling, doosre Claude model par retry karne ke liye fallback options, aur naye billing rules. Refusals, fallback aur billing section mein teeno ka summary hai.

Claude Fable 5 par refusals, fallback aur billing

Claude Fable 5 mein safety classifiers hain jo kuch requests ko decline kar sakte hain. Claude Mythos 5 mein yeh classifiers nahi hain, isliye yeh section sirf Claude Fable 5 par lagoo hota hai. Neeche har cheez ka short summary hai; poori guide ka link bhi diya gaya hai.

Refusals

Jab Claude Fable 5 kisi request ko decline karta hai, toh Messages API ek successful HTTP 200 response bhejta hai jismein stop_reason: "refusal" hota hai — yeh error nahi hai. Response mein yeh bhi bataya jata hai ki kis classifier ne request decline ki. Response shapes aur handling ke liye Refusals and fallback dekhein.

Fallback

Jis request ko Claude Fable 5 refuse karta hai, use aam taur par koi doosra Claude model handle kar leta hai. Retry karne ke teen tareeke hain:

  • Server-side: fallbacks parameter pass kar dein, API khud retry kar legi — Anthropic ke recommended models ke liye iska "default" mode use karein, ya khud apne models naam se dein (Claude API par abhi beta mein hai). Dekhein Server-side fallback.
  • Client-side: kisi bhi platform par client se retry karne ke liye SDK middleware use karein. Dekhein Client-side fallback.
  • Manual: retry ka logic khud likh lein — kisi bhi platform aur kisi bhi language mein. Dekhein Fallback credit.

Billing

Jo request koi bhi output generate hone se pehle refuse ho jaati hai, uska aapse charge nahi liya jata. Aur jab aap doosre model par retry karte hain, toh fallback credit model switch karne ki prompt-cache cost refund kar deta hai — yaani wahi cost do baar nahi bharni padti.

Availability

Claude Fable 5 aur Claude Mythos 5, dono 9 June 2026 se available honge:

  • Claude Fable 5 generally available hai — Claude API, Amazon Bedrock, Claude Platform on AWS, Google Cloud, aur Microsoft Foundry par.
  • Claude Mythos 5 generally available nahi hai: yeh sirf Project Glasswing ke approved customers ko limited availability mein milta hai. Access ke liye apni Anthropic, AWS ya Google Cloud account team se baat karein. Jinke paas Claude Mythos 5 ka access nahi hai, woh Claude Fable 5 use kar sakte hain — jo generally available hai aur wahi capabilities deta hai.

Claude Fable 5 aur Claude Mythos 5 par 30-din ka data retention lagoo hota hai aur yeh zero data retention ke saath available nahi hain: dono Covered Models hain. Dekhein Model-specific data retention requirements.

Prompting

Claude Fable 5 wahi prompting techniques samajhta hai jo baaki Claude models samajhte hain, bas long-context prompts aur reasoning instructions ko structure karne ke tareeke mein thoda farak hai. Dekhein Prompting Claude Fable 5.

Messages API par kya badla hai

Adaptive thinking hamesha on rehti hai

Claude Fable 5 aur Claude Mythos 5 par thinking hamesha enabled rehti hai; thinking: {"type": "disabled"} pass karna supported nahi hai. Thinking ki depth kam karni ho ya control karni ho, toh effort parameter ka istemaal karein.

Raw thinking content kabhi return nahi hoti

Claude Fable 5 aur Claude Mythos 5 par raw chain of thought kabhi return nahi ki jaati. Uski jagah thinking blocks mein kya aayega, yeh thinking.display setting tay karti hai:

  • "summarized" — thinking blocks mein reasoning ka ek padhne-yogya summary aata hai.
  • "omitted" (default) — thinking blocks aate hain lekin unka thinking field khaali rehta hai.

Multi-turn conversations mein, usi model par, thinking blocks ko bina badle waapas pass karein. Cross-model handling ke liye Claude Fable 5 aur Claude Mythos 5 par thinking output dekhein.
